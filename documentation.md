# BudgetBasics Project Report Outline

## 1. Problem Definition
Students may start managing allowances, scholarships, internship income, or part-time earnings without a simple way to plan and track money. BudgetBasics addresses this through educational explanations, visual learning, sample calculators, a temporary expense planner, savings planning, and awareness content.

## 2. Proposed Solution
A responsive Single Page Application focused on budgeting fundamentals, saving awareness, common money mistake prevention, infographic-based learning, and an educational chatbot.

## 3. Modules
- Home / welcome
- Budgeting Basics
- Needs vs Wants
- 50-30-20 Rule
- Savings Goals
- Expense Planner
- Money Mistakes
- Infographics / Explore Resources
- AI Chatbot Assistant
- Search, Sort, Filter
- About Us
- Feedback
- Contact Us
- Sitemap

## 4. Technical Design
HTML5 provides semantic structure, CSS3 provides the custom visual system, Bootstrap provides responsive layout utilities, JavaScript provides interactions and calculations, and JSON provides pre-populated learning/planning/chatbot/resource content.

## 5. Data & Privacy
No backend database, login storage, banking integration, payment processing, or permanent personal financial record storage is used.

## 6. Testing
Use `data/test-data.json` for calculator, savings, expense, and form test cases. Test on current Chrome, Firefox, Edge, and Safari where available. Use Google Lighthouse for performance, accessibility, and SEO validation.

## 7. Installation
Serve the project through a local static server because JSON files are loaded using the browser Fetch API.

## 8. Submission
Include the complete website folder, documentation, JSON/TXT test data, ReadMe file, and the mandatory MP4 demonstration video.
